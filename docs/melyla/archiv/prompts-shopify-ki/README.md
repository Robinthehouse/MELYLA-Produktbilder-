# Archiv: Prompts für Shopifys „Generate block"

Diese Textdateien waren Anweisungen an die KI im Shopify-Theme-Editor. Aus ihnen sind die Blöcke
entstanden, die seit dem 21.08.2026 als feste Sektionen im Theme-Repo
`Robinthehouse/melyla-shopify-theme` liegen (`sections/melyla-*.liquid`).

**Dieser Weg wird nicht weiterverfolgt.** Änderungen laufen ab jetzt über den Code im Theme-Repo und
werden per Push nach Shopify gespielt — nicht mehr über Prompts im Editor. Die Dateien bleiben hier,
weil sie dokumentieren, wie die Sektionen gemeint sind; derselbe Text steht auch als Kommentar oben
in jeder Sektionsdatei.

Verworfen wurden dabei sieben Blockvarianten, die es nie in eine Seite geschafft haben: ein zweiter
Hero, ein zweites Produktraster und ein alternatives Presse-Element.
